# Jarvis Master Roadmap

Ultimate Goal:
Build the fastest local AI assistant first, then evolve it into a React desktop/web interface with real-time streaming, agent mode, memory, vision, coding, automation, and multi-device sync.

Current Stack:
- STT: Parakeet TDT (MLX)
- LLM: Qwen3-4B-4bit (MLX)
- TTS: Qwen3-TTS (MLX)
- Local-first execution

Next Milestones:
1. Sub-second streaming voice.
2. Persistent runtime (no reloads).
3. Streaming TTS while thinking.
4. Unified Brain router.
5. React desktop UI.
6. Vision + OCR.
7. Memory.
8. Agent mode.
9. Phone companion.
10. Cloud sync (optional).
