# JARVIS ROADMAP

## PHASE 1 — Natural Conversation
- No repeated wake word after startup.
- Conversation Mode by default.
- Auto-standby after 15–20 seconds of silence.
- Auto-resume when user speaks.
- Fast (<1 sec perceived response).

---

## PHASE 2 — Native Wake Word
- Build our own offline wake-word engine.
- No Porcupine dependency.
- Train for "Jarvis".
- Support custom wake words.
- Near-zero CPU while idle.

---

## PHASE 3 — True Jarvis
- Start with macOS login.
- Interruptible speech.
- Long-term memory.
- Screen understanding.
- Control apps and system.
- Autonomous multi-step tasks.
- Fast, human-like conversation.
- Modular architecture.

---

RULE:
Whenever a better idea appears, improve this roadmap instead of changing direction.
Jarvis should never depend on Siri or another assistant.
